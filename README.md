# 🌌 Galaxy Particle in Motion

An interactive galaxy particle experience where users can control and move galaxy particles using real-time hand gestures.

## ✨ Features
- Interactive galaxy particle animation
- Hand movement detection
- Real-time gesture-based particle control
- Immersive visual experience
- Interactive browser-based experience

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Hand Tracking (if implemented)
